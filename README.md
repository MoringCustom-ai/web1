# Бот клуба «Шесть месяцев» (MVP)

Telegram-бот, который ведёт человека от первого касания до оплаты, выдаёт доступ
в закрытый чат клуба и каждый день собирает отметку по привычке. Отметки хранятся
в SQLite; бот сам публикует динамику в чат, админ получает выгрузку CSV.
Ежедневных опросов в чате нет — отметка только в боте.

## Структура

| Файл | Назначение |
|---|---|
| `main.py` | точка входа: polling + webhook-сервер Продамус + планировщик |
| `config.py` | **все тексты MVP в одном конфиг-файле** + настройки окружения |
| `database.py` | SQLite: users (utm, consent), subscriptions, challenges, participations, marks, payments |
| `utils.py` | TZ клуба, номер дня челленджа, календарь 🟩🟨🟥⬜, парсер deep-link с utm |
| `prodamus.py` | ссылка оплаты, проверка подписи `ipn_check`, парсер IPN, отключение автопродления |
| `chat_access.py` | автовыдача/отзыв доступа в закрытый чат |
| `webhook_server.py` | aiohttp `/prodamus/webhook` (success / refund) + `/healthz` |
| `handlers/user_flow.py` | /start→согласие→приветствие+видео→FAQ→тариф→оплата→кабинет→/today→/trend |
| `handlers/chat_events.py` | события чата: выдача прав вошедшему участнику |
| `handlers/admin.py` | /broadcast, /summary, /export (CSV), /start_challenge, /stop_sub |
| `chat_posts.py` | ежедневный и недельный посты динамики клуба в чат |
| `scheduler.py` | напоминание об отметке, вечерний/недельный посты, проверка истечений |

Логика отметок и серий взята из прототипа мини-приложения
(`Мини-приложение «Шесть месяцев» (Copy).html`): 3 варианта `ok/part/fail`,
`part` не сбрасывает серию, `fail` сбрасывает; пороги комментариев в чате
70% / 40%; сравнение «Ты vs Клуб».

Файл `Бот «Шесть месяцев».htm` — это сохранённая страница Claude-artifact:
сам контент рендерится динамически и в HTML не включён (в файле только
обёртка и JS-бандлы), поэтому тексты сценария восстановлены по ТЗ и лежат
в `config.py` — правятся там же.

## Быстрый старт

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполнить значения
python main.py
```

## Настройка (по шагам)

1. **@BotFather** → `/newbot`, получить токен → `BOT_TOKEN`.
2. В настройках бота через @BotFather включить `Update message content for Chat`
   и в коде поллинга уже запрошены `chat_member`/`my_chat_member` обновления.
3. **Закрытый чат клуба**: создать супергруппу, добавить бота админом с правами
   *Add members*, *Manage participants (restrict)*, *Delete messages*. Взять id
   чата (переслать сообщение от чата @userinfobot) → `CHAT_CLUB_ID`, сделать
   постоянную ссылку-приглашение → `CHAT_CLUB_INVITE_URL`.
4. **Продамус**: зарегистрировать магазин, создать товар с тремя планами
   (1 мес / 3 мес / 6 мес), в `config.TARIFFS[*]["prodamus_plan_id"]` вписать id
   планов, секретную подпись IPN → `PRODAMUS_SECRET_KEY`, id магазина →
   `PRODAMUS_SHOP_ID`. В кабинете Продамус указать URL вебхука:
   `https://ВАШ_ДОМЕН/prodamus/webhook`.
5. **HTTPS-домен**: любой reverse-proxy (caddy/nginx) на `WEBHOOK_PORT=8081`.
6. Видео-приветствие: загрузить видео боту, взять file_id → `VIDEO_WELCOME_URL`
   (или прямая ссылка).
7. Тексты оферты/политики → `DOCS_OFFER_URL`, `DOCS_PRIVACY_URL`.

## Команды пользователя

`/start` (с меткой источника) → согласие с документами → приветствие + видео +
описание клуба → FAQ → выбор тарифа → оплата → автодоступ в чат.
`/today` — отметка дня (✅ выдержал / 🟡 частично / ❌ сорвался),
`/trend` — личная динамика + «Ты vs Клуб», `/menu` — кабинет, `/pay` — продлить,
`/rules`, `/chat`, `/help`.

## Команды админа (`ADMIN_IDS`)

- `/broadcast [all|active|no_mark] текст` — рассылка (с троттлингом);
- `/summary` — воронка: касания → согласия → активные подписки → отметки сегодня → выручка;
- `/export` — CSV-выгрузка (пользователи, подписка, отметки по дням челленджа);
- `/start_challenge [title days=N key=...]` — запустить челлендж (без аргументов —
  «Дофаминовый детокс», 14 дней; кто в середине — включается с текущего дня);
- `/stop_sub <user_id>` — ручная отмена подписки + отзыв доступа.

## Что сознательно не входит в MVP (вторая версия)

«Привычка месяца»/«Своя привычка», точка А, заметки к отметкам, свой час
напоминания, редактирование текстов через админку (сейчас — `config.py`),
Telegram mini-app и визуальный календарь.

## Проверено

Смоук-тест БД и расчётов проходит: создание пользователя с utm → согласие →
подписка → вступление в челлендж «с текущего дня» → 10 отметок ok → статистика
дня, серии (`current=10, best=10`), выборка «серия 7+» для недельного поста,
форматирование всех текстов чата, импорт всех модулей (`python -c "import main"`).
